SYNK 시스템 아키텍처

랜덤 미션 숏폼 콜라주 SNS — 실제 운영 스택 기준 (BE: Spring Boot · EC2 / FE: React PWA · Vercel / 영상: AWS Lambda + FFmpeg)

요청 / 호출 (REST · JPA · Invoke) 비동기 · 푸시 (FCM) Frontend Backend Media DB External

핵심 흐름 — 미션 만료/전원 제출 시 Backend가 Lambda를 비동기 Invoke로 호출하고 응답을 기다리지 않습니다. Lambda가 FFmpeg로 콜라주를 합성해 S3(synk-videos)에 저장한 뒤 Backend 콜백 URL로 결과를 POST하면 상태가 PROCESSING → COMPLETED로 갱신됩니다. 실시간 채팅은 WebSocket(STOMP), 백그라운드 알림은 Firebase FCM 웹 푸시로 기기에 전달됩니다.
